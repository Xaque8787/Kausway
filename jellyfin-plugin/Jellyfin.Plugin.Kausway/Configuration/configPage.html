Kausway Remote Access

Private remote access to this server over Kausway peer-to-peer connections. Settings here are applied by kausway-host, which runs separately from Jellyfin.

The saved policy needs an kausway-host restart before it takes effect. In Docker, restart the container.

Transport policy

Relay only and P2P only are best effort in this version. See docs/transport-policies.md for what is and is not guaranteed.

WebSockets

Changes apply within a few seconds; turning WebSockets off closes open ones. Normal requests are not affected. When KAUSWAY_WEBSOCKETS or KAUSWAY_WEBSOCKET_ORIGIN is set for kausway-host, that value is applied again each time the host starts.

Host connection

Ignored when JELLYFIN_KAUSWAY_CONTROL_URL is set, as it is in the Docker image.
Ignored when JELLYFIN_KAUSWAY_CONTROL_TOKEN or JELLYFIN_KAUSWAY_CONTROL_TOKEN_FILE is set.
